# Catapulta-de-Canicas-con-Raspberry-Pi-Pico
Una catapulta hecha a base de madera, PLA y PTEG, programando "steppers", servomotores y sensores con MicroPython y usando una Raspberry Pi Pico como controlador principal. Realizado con la colaboración de mis compañeros de la asignatura de Robotics en la UT.
